# Vefforritun 1, 2026: Verkefni 5, Uppskriftaleit sýnilausn

Sýnilausn á [verkefni 5](https://github.com/vefforritun/vef1-2026-v5), sjá [verkefnalýsingu](verkefnalysing.md).

Notar klasa (`class`) til að útbúa annars vegar viðmót á móti [TheMealDB API](https://www.themealdb.com/api.php) og hins vegar til að birta niðurstöður.

Þarf að hafa Node.js og npm uppsett til að keyra:

```bash
npm install
npm run dev
npm run build # býr til keyrsluútgáfu í dist/
npm run preview # keyrir keyrsluútgáfu úr dist/
npm run lint # keyra eslint
```

Hægt er að herma eftir hægri tengingu með því að hafa `slow` í leitarstreng og villu með því að hafa `error`, t.d. `slow bread` eða `error bread`.
